## v1.4.0

First release with an installer-aware **update check**, plus the Genshin stretch fix and the redesigned UI.

### Updates
- **Check for updates**: Reframe asks GitHub for the latest release about 15 seconds after start (Settings can turn this off) and shows a banner when a newer version exists. Nothing is downloaded or installed until you click *Update now* in Settings.
- **Self-update** for both flavours: the installed copy runs the new setup silently, the portable copy overwrites its own files. Your config in `%LOCALAPPDATA%\Reframe` is never touched.
- Downloads are only accepted from this repository's releases, with the exact asset name, and must match the SHA-256 GitHub reports for the asset. The installed copy stages the update under `Program Files\Reframe\update`, which only administrators can write.
- **Installer**: starting the installed copy takes over the start-on-login task if it still pointed at another build. Setup refuses to run while Reframe is open.

> v1.3.1 and earlier have no update check, so download `Reframe-Setup-v1.4.0-win-x64.exe` (or the zip) by hand once. Later versions will be offered in the app.

### Window management
- **Genshin and other games that re-add their own title bar** are no longer fought forever: after three rounds of the game undoing every reapply, Reframe stops re-applying to that window and says so in the log. Editing or re-enabling the profile, or restarting the game, tries again.
- Reapplies are only counted when the window has actually drifted, so unrelated window events no longer eat the budget or raise false warnings.
- Window memory skips windows that a profile manages, so a game's own startup geometry is no longer remembered and dragged back on the next launch.
- DWM "Not Responding" ghost windows are ignored.

### UI
- Redesigned pages with shared card styles and clearer layouts (#3).

614 tests green.
